# logosAI: Greek text-to-speech

A web app for generating Greek speech with Google's [Gemini text-to-speech API](https://ai.google.dev/gemini-api/docs/speech-generation). It was built from a Google AI Studio template (React, Vite and an Express server).

## Features

- Greek speech generation with the Gemini TTS model (`gemini-3.1-flash-tts-preview`), with a choice of voices and speaking styles
- Library of Greek preset texts
- Translation into Greek before synthesis, using a Gemini text model
- Helper for Greek accents and diacritics, and a phonetics guide
- Playback speed control, history with favourites, and WAV export

Speech is generated by Google's hosted model; this app does not train or run its own speech model.

## Running locally

1. `npm install`
2. Copy `.env.example` to `.env` and set `GEMINI_API_KEY`
3. `npm run dev`, then open http://localhost:3000
